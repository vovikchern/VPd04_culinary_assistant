# Кулинарный помощник VK Bot

Бот для VK, который помогает подобрать рецепт по продуктам, искать блюда по названию, показывать карточку рецепта и давать короткий анализ питания.

Проект объединяет:
- VK-бот на `vkbottle`
- поиск и карточки рецептов через Spoonacular API
- перевод текста через MyMemory API
- разметку сообщений и клавиатуры для удобного меню в чате

## Что умеет бот

- Поиск рецептов по продуктам
- Поиск рецептов по названию блюда или кухне
- Показ случайного рецепта дня
- Показ карточки рецепта с ингредиентами и шагами
- Расширенный режим с анализом питания (БЖУ, калории)
- Русскоязычный интерфейс для пользователя
- Подсказки по шагам ввода для каждого сценария

## Требования

- Python 3.10+
- Виртуальное окружение
- Аккаунт ВКонтакте и токен сообщества
- API-ключ Spoonacular
- Email для MyMemory (по желанию, но желательно указать)

## Установка

1. Склонируйте проект или откройте папку проекта в терминале.
2. Создайте виртуальное окружение:

```bash
python -m venv venv
```

3. Активируйте его:

Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

Linux/macOS:

```bash
source venv/bin/activate
```

4. Установите зависимости:

```bash
pip install -r requirements.txt
```

## Настройка .env

Скопируйте файл `.env.example` в `.env` и заполните реальные значения:

```bash
copy .env.example .env
```

или на Linux/macOS:

```bash
cp .env.example .env
```

Пример содержимого `.env`:

```env
SPOONACULAR_API_KEY=ваш_ключ_здесь
MYMEMORY_EMAIL=ваш_email@example.com
VK_BOT_TOKEN=ваш_токен_сообщества
```

### Где получить ключи

- Spoonacular API:
  https://spoonacular.com/food-api/console
- VK bot token:
  - Создайте сообщество VK
  - Перейдите в `Управление → Работа с API`
  - Создайте ключ доступа
  - Включите Long Poll API и события входящих сообщений

## Запуск бота

Запускайте проект из корня проекта:

```bash
python -m food_vk_bot.main
```

Для Windows PowerShell это будет так же:

```powershell
cd E:\Projects_VC_ZC_home\VPd04
python -m food_vk_bot.main
```

Если вы запускаете из активированного виртуального окружения, можно использовать:

```powershell
.\venv\Scripts\python.exe -m food_vk_bot.main
```

## Горячие команды бота

После запуска бот отправляет главное меню. Основные действия:

- Что приготовить? — поиск рецептов по ингредиентам
- Найти рецепт — поиск по названию блюда или кухне
- Рецепт дня — показать случайный рецепт
- Карточка рецепта — выбрать рецепт по номеру или id
- Расширенный режим — показать карточку с анализом питания
- Помощь — показать справку

Вход в меню можно вернуть текстом:

- `0`
- `меню`
- `начать`
- `главное меню`

## Полезные замечания

- При отсутствии email в `MYMEMORY_EMAIL` переводчик будет работать в базовом режиме.
- Если API-ключ Spoonacular не указан, бот не сможет получать рецепты.
- При превышении квоты API бот покажет понятное сообщение пользователю.
